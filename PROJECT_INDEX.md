# Project Index: portfolio

Personal portfolio / case-study site for **Duran Köse** — bilingual (DA/EN),
dark-only, data-driven, statically exported. Live: <https://whoisduran.com/>

> Compact repo map for fast onboarding (generated by `/sc:index-repo`). For depth,
> see [`docs/`](./docs/README.md). Not a build artifact — hand-maintained.

## 🚀 Entry points

Static site — no CLI, API, or tests. Two pre-rendered documents, one per locale.

- **`app/(da)/layout.tsx`** / **`app/(en)/en/layout.tsx`** — the two root layouts.
  Each owns its `<html lang>` and exports its own `metadata` (title, description,
  canonical, `hreflang` alternates, OG/Twitter).
- **`app/RootShell.tsx`** — shared shell: fonts, `<div id="root">`, `LanguageProvider`,
  Person JSON-LD.
- **`src/components/SiteBody.tsx`** — section composition: Navbar → Hero → About →
  Snapshot → Projects → Timeline → Education → Services → Testimonials → Philosophy →
  Contact → Footer (+ BackToTop). Carries the `'use client'` boundary.

## 📦 Core modules

| Area | Path | Purpose |
|------|------|---------|
| Sections | `src/components/*.tsx` | One component per site section; read copy from `data/` + `i18n/ui.ts` |
| UI primitives | `src/components/ui/` | Button, Card, Tag, Reveal/Stagger, ImageGallery/Lightbox, BookingButton (lazy Cal.com), ScrollProgress (top scroll bar), GradientMesh (hero backdrop), ProjectVisual (exports `ProjectHeader` — card header strip), etc. |

| Images | `scripts/build-case-images.mjs` → `src/lib/caseStudyImages.ts` | Auto-discovers case-study images with `sharp` before each dev run/build (1600px full / 480px thumb WebP, content-hashed, numeric sort) |
| i18n | `src/i18n/` | `config` (LANGS, LANG_PATHS, LANG_META, otherLang), `LanguageContext`/`useLanguage`, `ui.ts` chrome strings + SEO copy |
| Metadata | `app/siteMetadata.ts` | Per-locale `Metadata` + Person JSON-LD; single source for canonical/`hreflang` |
| Hooks | `src/hooks/` | `useScrollSpy` (IntersectionObserver nav) · `useBodyScrollLock` (ref-counted) · `useEqualRowHeights` · `useModalA11y` |
| Motion | `src/lib/motion.ts` | Shared Framer Motion variants (reduced-motion aware) |

## 🔧 Configuration

- **`next.config.ts`** — `output: 'export'`, `trailingSlash: true`, `images.unoptimized`.
- **`tsconfig.json`** — single config; `next build` owns `jsx` and `next-env.d.ts`.
- **ESLint** — flat config (typescript-eslint + react-hooks + react-refresh); no `.eslintrc`,
  and deliberately no `eslint-config-next` (its plugins don't support ESLint 10 yet).
- **`deploy/nginx.conf`** — the server block, kept in-repo so its cache rules can't drift.
- **`.github/workflows/deploy.yml`** — builds and rsyncs `out/` to the VPS on push to `main`.

## 📝 Quick start

```bash
npm run dev       # prebuild images + next dev on :3000  (/ and /en/)
npm run build     # prebuild images + next build → out/  (CI runs this before deploy)
npm run lint      # ESLint
npm run preview   # serve the static export in out/
```

No test suite exists in this repo.
