# Portfolio — Developer Documentation

Personal portfolio / case-study site for **Duran Köse**, deployed at
<https://whoisduran.com/>.

A **Next.js 16 (App Router) + React 19 + TypeScript** site, statically exported.
All copy is data-driven and bilingual — Danish at `/`, English at `/en/`, each
pre-rendered as its own document — all case-study imagery is auto-discovered from
the filesystem, and the theme is dark-only. Each locale is one long scrollable
page; there are no routes beyond the two. There is no test suite.

> This `docs/` folder is the human-facing knowledge base. For Claude-specific
> guidance see [`../CLAUDE.md`](../CLAUDE.md); the root [`../README.md`](../README.md)
> is the short public blurb.

## Quick start

```bash
npm run dev       # build case-study images, then next dev on :3000  (/ and /en/)
npm run build     # build case-study images, then next build → out/  (CI runs this exact command)
npm run lint      # ESLint (flat config)
npm run preview   # serve the static export in out/ locally
```

Scripts are defined in [`../package.json`](../package.json). There is **no test
suite** in this repo.

## Tech stack

| Area | Choice | Notes |
|------|--------|-------|
| Framework | Next.js `^16.2` | App Router, `output: 'export'` — static files, no server |
| UI framework | React `^19.2` | one `'use client'` boundary at `SiteBody` |
| Language | TypeScript `~6.0` | typecheck runs inside `next build` |
| Styling | Tailwind CSS `^3.4` + PostCSS/autoprefixer | CSS-variable design tokens, dark-only |
| Fonts | `next/font/google` | Inter + Space Grotesk, self-hosted at build time |
| Animation | Framer Motion `^12.40` | scroll reveals, staggered lists |
| Images | `sharp` `^0.35` | WebP variants generated by a prebuild script |
| Booking | `@calcom/embed-react` `^1.5` | lazy-loaded Cal.com popup |
| Lint | ESLint `^10` + typescript-eslint + react-hooks/react-refresh | flat config; no `eslint-config-next` (ESLint 10 incompatible) |

## Where to make common changes

- **Change copy / add a project** → edit `src/data/*.ts` (see [DATA-MODEL.md](./DATA-MODEL.md)), not the JSX.
- **Add case-study screenshots** → drop images in `src/assets/case-studies/{project-id}/` (see [ARCHITECTURE.md](./ARCHITECTURE.md)).
- **Change section/button/label text** → edit `src/i18n/ui.ts` (see [I18N-AND-THEMING.md](./I18N-AND-THEMING.md)).
- **Adjust colors/spacing tokens** → edit the CSS variables in `app/globals.css`.
- **Change page title / description / social preview** → edit `src/i18n/ui.ts` (`seo`) and
  `app/siteMetadata.ts` (see [I18N-AND-THEMING.md](./I18N-AND-THEMING.md)).
